# Pack 28 — Debug + Edu

Řeší dva problémy: zpřesňuje Decode Lab šablonu, aby se po načtení vždy vykreslil alespoň výchozí obsah, a přidává stránku `/edu` s průvodkami k hlavním modulům. Edu část shrnuje práci se Scanner Labem, Decode Labem, State Labem, Inventurou a Administrací v krátkých návodech a přidává i ukázkové payloady a běžné troubleshooting kroky.
