# Pack 29 — Menu Delay

Přidává klientský skript pro horní menu, aby na desktopu nezmizelo okamžitě po opuštění kurzorem. Místo toho se zavření odloží o 3 sekundy a zruší se, pokud uživatel znovu najede myší na navigaci nebo její prvky. Chování se aplikuje pouze na prostředí s myší a hoverem, takže nezasahuje do mobilního ovládání.
