# Pack 10 — Registry Portability & Print Labels

Doplňuje slíbené operace nad Registry: CSV export, kontrolovaný CSV import a tiskový pohled jednotlivého štítku. Import očekává hlavičku `name,payload,tag,status,profile_id`; neplatné a duplicitní řádky přeskočí a vrátí jejich počet. Export obsahuje kompletní auditní tabulku Registry. Tisk se otevírá v nové kartě a nespouští generování žádného externího obsahu.
