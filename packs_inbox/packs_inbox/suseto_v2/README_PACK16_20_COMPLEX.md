# Complex Pack 16–20

Jeden balík slučuje: Inventory Sessions, Label Designer, Backup Center, Insight Lab a základní GS1/GTIN validaci. Operace pracují s vlastní Registry a vloženými payloady. Záloha vytváří ZIP `registry.json`, `registry.csv`, `sessions.json` a manifest; obnova validuje strukturu před zápisem, ale nahrazuje současná data — vždy nejdříve stáhni aktuální zálohu.
