# Unified Pack 23–26

Tento balík slučuje pět rozšíření do jednoho celku: Decode Pipeline & Pattern Library, Location Manager & Asset Timeline, Audit/Password/System Status rozšíření, Expected List Audit & Batch Print Sheets a Mobile Operator UI. Decode Lab zkouší bezpečné transformace vlastních payloadů (raw, hex, base64, url-decode), vyhodnocuje čitelnost, entropii a známé patterny. Location Manager zavádí základní katalog lokací a Timeline přidává provozní stopu pro relace a skeny.

Status stránka ukazuje přehled aktivního uživatele, souborů v datové složce a počtů auditních či timeline záznamů. Expected Audit porovnává očekávaný a skutečný seznam payloadů a Label Designer nově umí vytvořit i jednoduchý tiskový arch. Mobile stránka poskytuje zjednodušený tok pro operátora na telefonu. Funkce pracují s vlastními daty vloženými do aplikace.
