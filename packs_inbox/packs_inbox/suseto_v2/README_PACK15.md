# Pack 15 — Compact Category Navigation

Nahrazuje dlouhé horizontální menu rozbalovací navigací podle kategorií. Na desktopu se skupiny rozvinou při najetí myší a zavřou při opuštění; kliknutí zůstává dostupné pro dotyková zařízení a klávesnici. Kategorie: AIDC, Evidence, Analýza a Vývoj. Rozcestník zůstává jako přímý odkaz.
